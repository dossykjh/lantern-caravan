# 등불 원정대 — Lantern Caravan

작은 원정대(방패병·궁수·등불술사)가 황혼의 강둑을 따라 몬스터를 물리치며 나아가는 픽셀 횡스크롤 방치 RPG 웹게임. 폰 가로 화면 기준.

**플레이:** https://dossykjh.github.io/lantern-caravan/

폰에서는 첫 터치에 전체 화면으로 바뀐다. 브라우저 메뉴의 「홈 화면에 추가」로 설치하면 가로 전체 화면으로 실행된다.
보스(숲의 수문장)는 20구간마다 나온다. 바로 보려면 `?stage=20&atk=12` 를 붙여 연다.

- 그래픽: 캐릭터·배경·UI 모두 코드로 그린 픽셀 아트. 이펙트와 몬스터는 [pixelfx](https://github.com/patch-gg/pixelfx) (MIT, Patch · Hugo Duprez)
- 한글 글꼴: [Galmuri](https://github.com/quiple/galmuri) (SIL Open Font License 1.1, 이민서)
- 라이선스 전문은 `LICENSES/` 에 있다.
- 이 저장소는 빌드 결과물이다 (원본은 비공개 작업 폴더).
